# Product

## Register

product

## Users

Developers and platform teams who self-host ledgapi to keep an authoritative record of their API contracts. Two audiences: AI coding agents interact via MCP (no UI), and humans sign in to review contracts, manage users, and read the audit log. Humans arrive in a task-focused context: check what an endpoint looked like before changing it, review who mutated what, onboard a new team member.

## Product Purpose

A self-hosted, agent-native API contract registry. Agents query what endpoints exist before writing code and register new endpoints after creating them; humans audit that history through a login-protected web UI and docs site. Success means a developer trusts the registry as the source of truth and finds any contract in seconds.

## Brand Personality

Precise, trustworthy, quiet. A ledger: factual, calm, no theatrics. The interface should disappear into the task.

## Anti-references

- Marketing-style landing pages dressed up as tooling (gradient heroes, drenched color).
- Dense enterprise admin chrome: icon-spam sidebars, nested cards everywhere.
- Playful startup aesthetics: bounce easing, decorative motion, rounded-blob illustration.

## Design Principles

- Earned familiarity over novelty; standard affordances done exactly right.
- Data is the hero: tables, code, and badges get the typographic care.
- Restraint: one accent, used for actions and state only.
- Dark mode is a first-class citizen, not an afterthought.
- Accessibility floor is WCAG AA everywhere, AAA where cheap.

## Accessibility & Inclusion

WCAG 2.1 AA minimum: 4.5:1 body text, 3:1 large text and UI boundaries, visible focus indicators on every interactive element, reduced-motion support, keyboard-complete flows.
