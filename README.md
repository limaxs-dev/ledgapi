# ledgapi

> API contracts, remembered by your agents.

A self-hosted, agent-native **API contract registry**. AI coding agents interact through MCP (Model Context Protocol) to query what endpoints already exist before writing code and to register new endpoints after creating them. A read-only web UI lets humans review.

See [`docs/superpowers/specs/2026-08-21-ledgapi-design.md`](docs/superpowers/specs/2026-08-21-ledgapi-design.md) for the design spec.
